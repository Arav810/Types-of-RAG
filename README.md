Types of RAG – LangChain Implementations

This repository is a collection of projects exploring different Retrieval-Augmented Generation (RAG) techniques and LLM-powered applications built using LangChain.

Each folder demonstrates a specific RAG variant or use case, including hybrid search, Groq-powered inference, and chatbot implementations.

📂 Project Structure

rag/ – Simple/baseline RAG implementation.

hybridsearrag/ – Hybrid search–based RAG (dense + sparse retrieval).

graph/ – Graph RAG using Neo4j & LangChain integration.

groq/ – RAG pipeline accelerated with Groq LLM.

api/ – API backend (FastAPI + Streamlit integration).

venv/ – Local Python environment (ignored in git).

🛠️ Tech Stack

LangChain

Groq LLM

Neo4j (graph RAG)

FastAPI / Streamlit

Vector Stores: Qdrant , FAISS etc.
